# SiteMirror Inventiva — Descargas 5/10

Este repositorio almacena una de las diez partes del archivo de sitios web descargados por SiteMirror.

**Índice y código:** https://github.com/hs-development1/sitedownlowader.inventiva

Los archivos estarán en `SITES/<dominio>/runs/<identificador>/`, conservando las rutas originales del respaldo. Cada ejecución nueva utiliza un identificador diferente. La base completa se reconstruye con `ensamblar_sitio.py` del repositorio principal y el manifiesto central.

Este repositorio no contiene tokens ni contraseñas. No borres sus archivos mientras exista un manifiesto central que los referencie.
